Sonde isolée Windows Hello / WebAuthn PRF

Ce prototype crée un passkey temporaire sous l’origine locale localhost, puis demande deux signatures WebAuthn avec la même entrée PRF. Windows Hello peut demander une confirmation à chacune de ces étapes.

À savoir : le navigateur ne sait pas supprimer un passkey créé par cette page. Il restera associé à cette origine après le test; retire-le ensuite dans les paramètres Windows des passkeys si tu ne veux pas le conserver. Aucun secret PRF n’est affiché ni conservé par cette page.
